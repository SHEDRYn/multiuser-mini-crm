# Мини-CRM API

Многопользовательская мини-CRM система с поддержкой нескольких организаций (multi-tenant).

## Архитектура

Проект построен по принципу чистой архитектуры с разделением на слои:

```
app/
├── api/          # API endpoints (роуты, схемы запрос/ответ)
├── services/     # Бизнес-логика
├── repositories/ # Работа с БД (data access layer)
├── models/       # ORM-модели SQLAlchemy
├── schemas/      # Pydantic схемы для валидации
├── core/         # Конфигурация, безопасность, зависимости
└── db/           # Настройка БД и сессий
```

### Слои приложения

1. **API Layer** (`app/api/`) - HTTP endpoints, маршрутизация, обработка запросов/ответов
2. **Service Layer** (`app/services/`) - Бизнес-логика, правила, валидации
3. **Repository Layer** (`app/repositories/`) - Абстракция над БД, CRUD операции
4. **Model Layer** (`app/models/`) - ORM модели данных

## Технологический стек

- **Python 3.10+**
- **FastAPI** - Async web framework
- **SQLAlchemy 2.0** - ORM + Alembic для миграций
- **PostgreSQL** - База данных
- **Pydantic** - Валидация данных и настройки
- **JWT** - Аутентификация (access/refresh токены)
- **Docker** - Контейнеризация
- **Pytest** - Тестирование

## Функциональность

### Сущности
- **Organizations** - Организации (компании)
- **Users** - Пользователи системы
- **OrganizationMembers** - Связь пользователей с организациями + роли
- **Contacts** - Контакты
- **Deals** - Сделки с воронкой продаж
- **Tasks** - Задачи по сделкам
- **Activities** - Таймлайн активности по сделкам

### Роли и права доступа
- **owner** - Полный доступ к организации
- **admin** - Административный доступ
- **manager** - Управление сущностями (без настроек организации)
- **member** - Просмотр всего, редактирование своих сущностей

### API Endpoints
- `/api/v1/auth/*` - Аутентификация (регистрация, вход)
- `/api/v1/organizations/*` - Управление организациями
- `/api/v1/contacts/*` - Управление контактами
- `/api/v1/deals/*` - Управление сделками
- `/api/v1/tasks/*` - Управление задачами
- `/api/v1/analytics/*` - Аналитика и отчеты
